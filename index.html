Liberar Controle Real de Mouse e Teclado

Navegadores bloqueiam o controle direto do mouse do Windows por segurança. Escolha a opção ideal para o cliente (zero Python, zero dependência externa — funciona nativamente no Windows 10, 11 e Windows Server):

Opção 1 — Automático em Segundo Plano (Clientes Fixos) Sem Admin

Execute 1 única vez no PC do cliente. Registra o protocolo ottimize-ctrl:// e, nos próximos atendimentos, ao clicar em Compartilhar Tela Real, o controle ativa sozinho em segundo plano sem janela preta.

Opção 2 — Ativador Avulso (Sem Instalação) Portátil

Ideal para atendimentos pontuais. O cliente dá 2 cliques e, quando fechar a janela, o controle é encerrado na hora sem deixar nada instalado.

Como Usar e Publicar na Nuvem

  1. Salve este arquivo como index.html (e coloque a imagem Ottimize.jpg na mesma pasta, se desejar).
  2. Publique em HTTPS gratuito (ex.: Netlify Drop, Vercel ou GitHub Pages). O HTTPS libera o compartilhamento de tela real e a Nuvem WebRTC automaticamente.
  3. Envie o link ao cliente. Ele clica em Compartilhar Tela Real (selecione Tela Inteira) e informa o código de 6 dígitos.
  4. Se houver firewall pfSense bloqueando UDP, abra Firewall / TURN e marque Forçar Modo Relay.

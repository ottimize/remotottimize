Como Ativar a Nuvem WebRTC

Este site já vem configurado com a Nuvem PeerJS integrada (gratuita e sem precisar configurar banco de dados). Para acessar clientes reais em outros computadores pela internet, você só precisa abrir este arquivo em um endereço HTTPS real:

Passo 1 — Salve este arquivo

Copie o código deste arquivo e salve no seu computador como index.html (dentro de uma pasta vazia, ex: acessoweb).

Passo 2 — Publique grátis em 30 segundos (HTTPS)

  • Netlify Drop (mais rápido): acesse app.netlify.com/drop e arraste a pasta com o index.html. Ele gera um link HTTPS na hora!
  • GitHub Pages / Vercel / Cloudflare Pages: suba o index.html e ative o Pages.

Passo 3 — Conecte-se ao cliente

Envie o seu link HTTPS para o cliente. O indicador no topo ficará verde (Nuvem WebRTC: Online). O cliente clica em Compartilhar Tela Real, te passa o código de 6 dígitos e você conecta no Modo Técnico!
